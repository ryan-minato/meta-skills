# frontend

[English](README.md)

面向具有用户可见视觉界面的项目的 meta-skill：设计描述与视觉语言。在 `core`
之上按项目安装，且仅当目标项目确实有前端时安装——本目录不属于默认安装集合。

这些技能是**一次性的**：harness 搭建完成并通过验证后，由 `core` 的移除技能将
它们连同其余技能一并删除。

```bash
npx skills add ryan-minato/meta-skills --skill <skill-name>
```
