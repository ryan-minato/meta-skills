# Voice Conversion, Separation & Audio Processing

Read when the target converts voices, separates sources, or does
general audio processing and augmentation. One line and an entry point
per tool; fetch install and pipeline details from the entry point. No
entry is a recommendation.

## Tools

| Tool | One line | Docs |
|---|---|---|

| Seed-VC | zero-shot voice conversion | <https://github.com/Plachtaa/seed-vc> |
