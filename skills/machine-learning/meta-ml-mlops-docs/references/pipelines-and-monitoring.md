# ML Pipelines & Monitoring

Read when the target orchestrates ML workflows or monitors models and
data in production. One line and an entry point per tool; fetch
deployment and config details from the entry point. Kubeflow,
Prometheus, and Grafana deploy as services — see their docs. No entry is
a recommendation.
