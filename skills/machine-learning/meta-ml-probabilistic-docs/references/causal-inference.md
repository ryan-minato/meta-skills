# Causal Inference

Read when the target estimates causal effects or discovers causal
structure. One line and an entry point per tool; fetch install commands
and API details from the entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| DoWhy | causal-assumption-explicit effect estimation | <https://www.pywhy.org/dowhy/> |
| causal-learn | causal discovery algorithms | <https://causal-learn.readthedocs.io/> |
| EconML | ML-based heterogeneous treatment effects | <https://github.com/py-why/EconML> |
| CausalML | uplift modeling and causal ML | <https://causalml.readthedocs.io/> |
| DoubleML | double/debiased machine learning | <https://docs.doubleml.org/> |
| Tigramite | causal discovery for time series | <https://github.com/jakobrunge/tigramite> |
