# Probabilistic Programming & Bayesian Inference

Read when the target builds Bayesian models or runs MCMC/variational
inference. One line and an entry point per tool; fetch install commands
and API details from the entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| PyMC | Bayesian modeling in Python | <https://www.pymc.io/> |
| ArviZ | exploratory analysis of Bayesian inference results | <https://python.arviz.org/> |
| Stan | the Stan probabilistic language and samplers | <https://mc-stan.org/> |
| CmdStanPy | Python interface to CmdStan | <https://mc-stan.org/cmdstanpy/> |
| Pyro | deep probabilistic programming on PyTorch | <https://pyro.ai/> |
| NumPyro | Pyro's NumPy/JAX backend | <https://num.pyro.ai/> |
| TensorFlow Probability | probabilistic layers and inference on TensorFlow | <https://www.tensorflow.org/probability> |
| BlackJAX | composable samplers in JAX | <https://blackjax-devs.github.io/blackjax/> |
