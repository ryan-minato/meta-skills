# Core Model, Data & File Libraries

Read when any Hugging Face model, data, or file-format library is in
play — the default entry for every Hugging Face project. One line and an
entry point per library; fetch install commands and API details from the
entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| Transformers | text, vision, speech, and multimodal models under one API | <https://huggingface.co/docs/transformers> |
| Diffusers | diffusion models for image, video, and audio generation | <https://huggingface.co/docs/diffusers> |
| Sentence Transformers | embeddings, semantic retrieval, and rerankers | <https://sbert.net/> |
| timm | vision models, pretrained weights, and training components | <https://huggingface.co/docs/timm> |
| Transformers.js | model inference in the browser and Node.js | <https://huggingface.co/docs/transformers.js> |
| Datasets | data loading, streaming, processing, and sharing | <https://huggingface.co/docs/datasets> |
| Tokenizers | high-performance tokenizers backed by Rust | <https://github.com/huggingface/tokenizers> |
| Safetensors | safe, fast model-weight serialization | <https://huggingface.co/docs/safetensors> |
| huggingface_hub | the Hub's Python client | <https://huggingface.co/docs/huggingface_hub> |
| Hub (incl. Xet storage) | model, dataset, and Space hosting and its storage backend | <https://huggingface.co/docs/hub> |
