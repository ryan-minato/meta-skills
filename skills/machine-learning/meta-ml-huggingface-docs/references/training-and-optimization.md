# Training, Evaluation & Optimization

Read when the target trains, finetunes, evaluates, or exports models
with Hugging Face tooling. One line and an entry point per library;
fetch install commands and config details from the entry point. No entry
is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| Accelerate | device placement and multi-GPU/multi-node launch for PyTorch loops | <https://huggingface.co/docs/accelerate> |
| PEFT | parameter-efficient finetuning (LoRA, AdaLoRA, IA³, prompt tuning) | <https://huggingface.co/docs/peft> |
| TRL | LLM post-training: SFT, DPO, GRPO, KTO, reward models | <https://huggingface.co/docs/trl> |
| AutoTrain | low-code training and finetuning | <https://huggingface.co/docs/autotrain> |
| Kernels | optimized compute kernels loaded from the Hub | <https://huggingface.co/docs/kernels> |
| Optimum | ONNX Runtime, OpenVINO, quantization, and hardware-accelerated export | <https://huggingface.co/docs/optimum> |
| Evaluate | shared evaluation metrics | <https://huggingface.co/docs/evaluate> |
| LightEval | LLM evaluation harness across backends | <https://huggingface.co/docs/lighteval> |
