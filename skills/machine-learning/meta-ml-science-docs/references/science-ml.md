# Medical, Biological, Chemical & Physics ML

Read for any scientific-ML target. One line and an entry point per
tool; fetch install channel (PyPI or conda-forge) and API details from
the entry point. No entry is a recommendation.

## Libraries

| TorchIO | 3D medical image loading and augmentation | <https://docs.torchio.org/> |
