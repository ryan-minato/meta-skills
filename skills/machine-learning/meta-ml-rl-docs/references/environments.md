# Environments & Simulators

Read when the target defines, wraps, or runs environments and
simulators. One line and an entry point per tool; fetch install and
scene/asset details from the entry point. CARLA and Isaac Lab install as
applications — see their docs. No entry is a recommendation.

## Environments
