# Model Compilers & Cross-Platform Runtimes

Read when the target exports models to a compiled or cross-platform
runtime, including mobile and edge. One line and an entry point per
tool; fetch export flows and runtime APIs from the entry point. No entry
is a recommendation.

## Tools

| Tool | One line | Docs |
|---|---|---|
| ONNX | the open model-exchange format | <https://onnx.ai/> |
| ONNX Runtime | cross-platform accelerated ONNX inference | <https://onnxruntime.ai/> |
| NVIDIA TensorRT | optimizing compiler and runtime for NVIDIA GPUs | <https://docs.nvidia.com/deeplearning/tensorrt/> — llms.txt: <https://docs.nvidia.com/llms.txt> |
