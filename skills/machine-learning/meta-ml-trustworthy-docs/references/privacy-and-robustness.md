# Privacy, Robustness, Fairness & Interpretability

Read when the target trains with differential privacy, tests
adversarial robustness, audits fairness, redacts PII, or explains
models. One line and an entry point per tool; fetch install commands
and API details from the entry point. No entry is a recommendation.
