## Harness Proposals

After completing a task, if you noticed a harness gap — a missing rule, a
stale document, a procedure worth a skill — propose it in one or two
sentences with the evidence from this task. Do not apply it. The user
decides; when in doubt or unanswered, the proposal is not adopted. Never
edit the harness (this file, knowledge documents, skills, checks) except
on an explicit user decision.
