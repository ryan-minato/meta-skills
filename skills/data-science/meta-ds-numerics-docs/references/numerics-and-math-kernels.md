# Math Kernels, Sparse Solvers & C/C++ Numerics

Read when the target links math kernels, sparse solvers, or C/C++
numerical libraries. One line and an entry point per library; most
install from system packages or source — fetch build details from the
entry point. No entry is a recommendation.
