# NVIDIA RAPIDS GPU Data Science

Read when the target runs data science on NVIDIA GPUs. One line and an
entry point per tool; fetch install channels (conda/pip with CUDA
matching) from the entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| RAPIDS | the GPU data-science suite's documentation hub | <https://docs.rapids.ai/> |
| cuDF | pandas-compatible dataframes on GPUs | <https://docs.rapids.ai/api/cudf/stable/> |
| cuML | scikit-learn-compatible ML on GPUs | <https://docs.rapids.ai/api/cuml/stable/> |
| cuGraph | GPU graph analytics | <https://docs.rapids.ai/api/cugraph/stable/> |
| cuSpatial | GPU geospatial operations | <https://docs.rapids.ai/api/cuspatial/stable/> |
| Dask-CUDA | multi-GPU Dask clusters | <https://docs.rapids.ai/api/dask-cuda/stable/> |
| RMM | GPU memory management | <https://docs.rapids.ai/api/rmm/stable/> |
| CuPy | NumPy/SciPy-compatible arrays on GPUs | <https://docs.cupy.dev/> |
