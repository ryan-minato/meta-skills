# Numerics & Statistics

Read when the target computes on arrays or runs statistical models. One
line and an entry point per tool; fetch install commands and API details
from the entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| NumPy | the standard array library | <https://numpy.org/doc/> |
| SciPy | linear algebra, optimization, statistics, and signal processing | <https://docs.scipy.org/doc/scipy/> |
| Numba | JIT compiler for numerical Python | <https://numba.readthedocs.io/> |
| CuPy | NumPy/SciPy-compatible arrays on GPUs | <https://docs.cupy.dev/> |
| statsmodels | statistical modeling and econometrics | <https://www.statsmodels.org/> |
| scikit-learn | preprocessing, clustering, and classic ML for analysis | <https://scikit-learn.org/> |
| PyMC | Bayesian modeling | <https://www.pymc.io/> |
| ArviZ | exploratory analysis of Bayesian results | <https://python.arviz.org/> |
| lifelines | survival analysis | <https://lifelines.readthedocs.io/> |
