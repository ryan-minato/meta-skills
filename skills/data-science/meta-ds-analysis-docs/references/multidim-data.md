# Multidimensional Labeled Data

Read when the target works with labeled N-dimensional arrays (climate,
imaging, sensor data). One line and an entry point per tool; fetch
install commands and API details from the entry point. No entry is a
recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| xarray | labeled N-D arrays with NetCDF/Zarr/Dask integration | <https://docs.xarray.dev/> — llms.txt: <https://docs.xarray.dev/llms.txt> |
| rioxarray | rasterio-backed geospatial extension for xarray | <https://corteva.github.io/rioxarray/> |
| Rasterio | raster I/O on GDAL | <https://rasterio.readthedocs.io/> |
| netCDF4 | Python interface to NetCDF files | <https://unidata.github.io/netcdf4-python/> |
