# Data Quality & Validation

Read when the target validates schemas or monitors data quality. One
line and an entry point per tool; fetch install commands and API
details from the entry point. No entry is a recommendation.

## Libraries

| Tool | One line | Docs |
|---|---|---|
| Pandera | dataframe schema validation | <https://pandera.readthedocs.io/> |
| Great Expectations | data quality expectations and checkpoints | <https://docs.greatexpectations.io/> |
| Evidently | data and model quality monitoring and reports | <https://docs.evidentlyai.com/> — llms.txt: <https://docs.evidentlyai.com/llms.txt> |
| Cleanlab | label-error detection in datasets | <https://docs.cleanlab.ai/> |
| Pydantic | typed data validation for records and configs | <https://pydantic.dev/docs/> — llms.txt: <https://pydantic.dev/llms.txt> |
