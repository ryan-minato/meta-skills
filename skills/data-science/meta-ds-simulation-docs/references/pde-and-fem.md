# PDE, FEM & Multiphysics

Read when the target solves PDEs, meshes geometry, or runs multiphysics
simulations. One line and an entry point per tool; most install from
source, containers, or system packages — fetch build details from the
entry point. The sparse solvers underneath (PETSc, Trilinos, hypre,
SLEPc, MUMPS, SuperLU_DIST) are recorded with the numerics stack. No
entry is a recommendation.
