# Choosing a License

Read when the repository has no LICENSE and will be public.

1. The choice is the user's — legal consequences follow from it. Frame
   the decision with <https://choosealicense.com/>: fetch it live and
   walk the user through the current decision points (permissive versus
   copyleft, patent language, ecosystem norms).
2. Check the dependencies' licenses before proposing: a copyleft
   dependency can constrain the project's own choice. Flag conflicts to
   the user; never resolve them silently.
3. Use the exact canonical license text, fetched live — never
   paraphrased, never trimmed — with the copyright line filled per the
   license's own instructions.
4. Put the file where GitHub detects it (verify the current recognized
   filenames live) so the repository shows its license in the UI and
   API.
5. No license means all rights reserved: if the user declines to choose,
   record in the AGENTS.md deposit that the project is intentionally
   unlicensed, so nobody adds one casually later.
