# Merge Request Template Skeleton

Copy the block below to
`.gitlab/merge_request_templates/Default.md`, then rework every line
against the flow agreed with the user and delete the guidance comments.
A section nobody will fill is deleted, not kept.

```markdown
## Summary

<!-- One paragraph: what changes and why. Link the issue this closes. -->

## Changes

- <change>

## Testing

<!-- How this was verified: commands run, what was observed. -->

## Review notes

<!-- What the reviewer should look at first; the risky spots. -->
```
